# 同传 SI

使用 PySide6 Widgets 编写的 Windows 双向同声传译桌面应用，接入 `qwen3.8-livetranslate-flash-realtime`。界面不使用 QML。

## 启动

需要 Python 3.12 或更高版本及 [uv](https://docs.astral.sh/uv/)。在项目目录执行：

```powershell
uv sync --group dev
uv run python -m si
```

也可以运行项目中的 `run.ps1`。安装后提供 `si` 桌面入口。

首次启动不会录音、播放或连接计费 API。打开设置，填写百炼地域、业务空间 ID 和 API Key。密钥可只保留在当前进程，也可选择保存到 Windows 凭据管理器；普通配置文件不包含密钥。环境变量 `DASHSCOPE_API_KEY` 和 `DASHSCOPE_WORKSPACE_ID` 也可提供初始配置。

“在 Windows 凭据管理器中保存密钥”默认选中，保存时会立即读回校验。保存成功后重启自动加载，已保存的密钥优先于环境变量；取消勾选则移除该业务空间的已存密钥，仅在当前进程使用。此选项会随普通配置保存，设置窗口显示密钥是否已经保存。

## 接线

需要事先安装提供两条独立连接的虚拟音频驱动，例如 VB-CABLE A/B。应用不会自动安装或改动系统音频驱动。

| 位置 | 选择 |
| --- | --- |
| SI 我的发言输入 | 真实麦克风 |
| SI 我的发言输出 | CABLE-A Input |
| 会议软件麦克风 | CABLE-A Output |
| 会议软件扬声器 | CABLE-B Input |
| SI 对方发言输入 | CABLE-B Output |
| SI 对方发言输出 | 真实耳机或扬声器 |

本机输入输出端点由 Qt Multimedia 枚举，设置中保存设备 ID。缺失的设备会显示已断开，不自动回退。输入输出分别转换成服务端确认的 PCM 采样率，使用 libsoxr 的流式重采样。

设备测试会在本地采集三秒输入电平并播放一段低音量提示音，不上传音频。建议先用耳机验证双向链路。当前版本尚未接入声学回声消除；使用扬声器外放时，麦克风可能拾取译音并再次翻译，不能将此版本视为已完成外放 AEC 验收。

## 控制与字幕

- 两条链路可以独立开始、暂停、恢复、停止、静音和调整音量。
- 每路“译为”旁的“音色”菜单独立选择并自动保存，支持甜甜 Tina（默认）、苏瑶 Serena、晨煦 Ethan、四月 Maia、卡捷琳娜 Katerina、甜茶 Ryan、予安 Theo Calm。停止或暂停后可修改，下一次启动或恢复时生效。
- 静音会清空该路待播音频，会话继续工作；暂停停止上传并结束当前会话，恢复时建立新会话。
- 原文与译文显示开关独立，关闭字幕不影响译音。
- 3.8 服务端原文识别始终开启；隐藏本地文字不关闭服务端生成。
- 字幕按源项、译文项及会话关联，最终结果替换增量结果，最多保留最近 300 段。
- 默认不保存音频或字幕。设置中选择各方向的导出内容，再手动导出 UTF-8 文本。
- 术语表为每个方向分别配置；连接前发送到服务端。
- 窗口关闭会停止两条链路并释放音频和网络线程；托盘菜单支持显示、隐藏和紧急静音。

网络瞬断使用有限次数的指数退避重连，鉴权或参数错误直接显示故障。重连时关闭旧音频缓冲，并使用新的会话代次隔离迟到的数据。上传积压超过约 500 ms 时重新同步；译音积压超过 8 秒时停止该方向，防止延迟无限增长。服务端结束会话时按恢复策略重建，不能保证跨会话语境自动延续。

音色通过 3.8 的 `session.audio.output.voice` 发送，启动采集前核对 `session.updated` 中确认的音色；缺失或不一致时显示错误并写入日志，避免选择未生效。旧配置缺少音色字段时使用 Tina。上述七个音色已于 2026-10-09 在北京地域的 3.8 API 上完成配置确认验证，未录音或上传音频；音色听感和其他地域仍需实际验证。可用 `uv run python tools/check_voice_api.py Serena` 单独检查当前地域的音色配置，此工具连接真实 API，但不启动音频设备。

## 日志

应用启动后自动记录 UTF-8 运行日志，主界面右上角的文档图标和托盘菜单可以查看实时日志、筛选错误、复制堆栈和选择历史日志。查看器显示当前程序实际使用的完整路径，并提供打开文件夹按钮。默认位置为 Qt 的本地应用数据目录 `logs/si.log`，Windows 通常是 `%LOCALAPPDATA%/SI/SI/logs/si.log`；从 Windows 打包应用启动时可能重定向至该应用的 LocalCache 目录，以查看器显示的路径为准。

日志包含时间、级别、线程、模块、方向和会话代次，记录启停、暂停、静音、设备与采样格式、会话配置确认、重连原因、配置或导出失败以及异常堆栈。使用独立写入线程，每个文件最多 5 MiB，保留 5 份历史文件。正常关闭会等待待写日志落盘。

默认级别为 INFO，每 5 秒记录播放积压、接收/已写入音频时长和欠载统计；溢出时记录单次返回量及设备状态。DEBUG 额外记录配置读写和网络握手步骤。不会记录原始音频、完整 API 消息、字幕内容或术语表；API Key 和鉴权字段会脱敏。日志不代替手动字幕导出。

```powershell
uv run python -m si --log-level DEBUG
uv run python -m si --log-dir D:\SI-logs
```

日志目录不可写时会尝试使用系统临时目录下的 `SI-logs`，并在状态栏提示。更新前已经打开的程序需要重启才能使用日志功能。

音频设备打开成功后才显示“翻译中”。设备失败会记录输入/输出方向、设备名称、Qt 错误代码和设备状态；连接成功不代表本地音频已经启动。

## 验证

```powershell
uv run pytest -q -k test_si_
uv run python -m si --smoke-test
uv run python -m si --list-devices
```

离线测试覆盖协议握手、音频发送与关闭、双路隔离、字幕关联、格式转换、队列边界、配置和 GUI 行为。实际模型权限、计费、端到端延迟、虚拟驱动路由以及会议软件兼容性需要在真实环境中验证。

以上命令只运行新应用的测试。运行全部历史测试时，原型脚本 `test_1.py` 的缺失密钥测试仍有一项失败：该脚本目前使用固定密钥，未读取测试预期的环境变量。新应用不会读取原型脚本中的凭证；原型保留原状。

实现目录为 `src/si/`；原有实验脚本保留。完整架构说明见 `docs/si-architecture.md`。
